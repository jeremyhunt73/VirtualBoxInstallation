<h1>Installing VirtualBox and Server 2016</h1>

<h2>Description</h2>
This project consists of the installation of VirtualBox VM with a Windows Server 2016 OS. A virtual machine is crucial for doing labs in a safe enviroment, what happens inside the VM won't affect the host machine. This can be done in other software applications like VMware and Hyper-V, I chose VirtualBox because of preference. This lab is meant to be basic and the foundation of future projects.
<br />


<h2>Software Used</h2>

- <b>Latest version of VirtualBox</b> 

<h2>Environments Used </h2>

- <b>Windows Server 2016</b>
